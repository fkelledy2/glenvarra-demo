# Glenvarra College – demo school website

![Glenvarra College homepage](screenshot-home.png)

A WordPress block theme for **Glenvarra College**, a *fictional* independent, multi-denominational day and boarding school in Co. Wicklow, Ireland.

## View the live demo (no install needed)

**[Open the demo in WordPress Playground](https://playground.wordpress.net/?blueprint-url=https://raw.githubusercontent.com/fkelledy2/glenvarra-demo/main/blueprint.json)**

The link starts a full WordPress site in your browser, installs the theme and builds the demo content: about 30 pages, a dropdown menu, news, events and an enquiry form. It takes 10–20 seconds the first time. You are logged in as an administrator, so you can also explore wp-admin.

Each visitor gets their own private copy and nothing is saved, so feel free to click around and edit.

## Install on a real WordPress site

1. Download `glenvarra.zip`. The theme source is in the `glenvarra/` folder.
2. In WordPress, go to **Appearance → Themes → Add New → Upload Theme**, choose the zip, then click **Activate**.
3. The demo content is created automatically. To run it again, go to **Appearance → Glenvarra demo**.

A fresh WordPress install is recommended. Activation changes the site title, homepage, news page and permalink settings.

## What's included

- **Pages:** About, Admissions (fees, expression of interest, Admissions Policy, Annual Admissions Notice), Academic (Junior Cycle, Transition Year, Leaving Certificate), Junior School, Boarding, Arts, Sport & activities, Policies (with a Child Safeguarding Statement), Calendar & term dates, Parents, Past Pupils, Careers, Privacy and Contact.
- **Events:** an Events post type, with an upcoming-events list on the homepage and the calendar page.
- **Forms:** an enquiry form and a newsletter sign-up. Submissions are stored under **Enquiries** in wp-admin and emailed to the site admin address.
- **Privacy:** no Google Fonts, maps, analytics or third-party cookies.

All names, people, contact details and figures are invented.
